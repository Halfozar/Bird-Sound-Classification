# Bird Sound Classification using Streamlit

This project classifies bird sounds using classical machine learning and audio signal processing.

## Features

- MFCC Feature Extraction
- Spectral Features
- SVM Classification
- Audio Recording
- Audio Upload
- Streamlit Web App

## Classes

- Crow
- Bluejay
- Cuckoo
- Kingfisher
- Noise
